# 墨写 · Flutter Path A

这是桌面手写软件的新开发线：**Flutter + pressure-aware canvas**，直接在 GitHub 分支中推进，不要求本地先搭开发环境。

## 当前分支

`flutter-a-dev`

## 当前阶段：MVP-04

这一阶段开始把“能写”推进到“适合老师实际板书”：

- macOS / Windows 桌面端
- pressure-aware stylus input
- 平滑笔迹
- 画笔 / 直线 / 橡皮 / 精细橡皮
- 选择 / 套索
- 黑、红、蓝、绿、黄等常用颜色
- 2 / 4 / 7 / 10 px 快速粗细
- 圆珠笔 / 钢笔 / 荧光笔预设
- 收藏笔槽左右切换
- Undo / Redo / 清空
- 深色软件壳 + 白色书写区域
- 键盘快捷键
- 无限画布基础能力

## 核心底座

当前采用 `fluera_canvas`。它提供 macOS / Windows 支持、pressure-aware stylus input、平滑处理、橡皮、像素级橡皮、选择、套索、无限缩放/平移以及持久化基础能力。

选择它的原因是：A 路径的重点是**开发效率 + 尽快验证真实手写体验**，而不是第一天自己从 PointerEvent、Path、缓存、命中测试全部造轮子。

## GitHub 云端开发

本项目按照“GitHub 直接开发”的方式推进：

1. 修改代码直接提交到 `flutter-a-dev`。
2. GitHub Actions 自动执行 `flutter analyze` 与 `flutter test`。
3. 同时在 GitHub-hosted macOS / Windows runner 上进行桌面构建。
4. 本地电脑不承担开发环境和构建环境。

## 已确定的交互方向

- 普通书写时只显示干净笔迹，不额外显示控制点。
- 使用“选择”或“套索”选中几何图案后，再进入选择/变换状态。
- 直线工具只负责快速画直线，不在完成后长期显示控制点。
- 普通橡皮保留整笔擦除逻辑；精细橡皮用于擦掉笔迹局部。
- 收藏笔槽作为高频工具区，后续继续加入长按编辑、拖动与吸附。
