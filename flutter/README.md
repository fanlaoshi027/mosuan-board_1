# 墨写 · Flutter Path A

这是桌面手写软件的新开发线：**Flutter + pressure-aware canvas**，直接在 GitHub 分支中推进，不要求本地先搭开发环境。

## 当前分支

`flutter-a-dev`

## 当前阶段：MVP-02

目标不是先做完整产品，而是先把“写”这件事做好：

- macOS / Windows 桌面端
- 压感笔输入
- 平滑笔迹
- 画笔 / 橡皮 / 选择
- 颜色与粗细
- 收藏笔槽
- Undo / Redo / 清空
- 深色软件壳 + 白色书写区域
- 键盘快捷键
- 无限画布基础能力

## 核心底座

当前采用 `fluera_canvas`。它提供 macOS / Windows 支持、pressure-aware stylus input、平滑处理、橡皮、选择、无限缩放/平移、持久化基础能力以及较完整的 Flutter 桌面输入处理。

选择它的原因是：A 路径的重点是**开发效率 + 尽快验证真实手写体验**，而不是第一天自己从 PointerEvent、Path、缓存、命中测试全部造轮子。
