# 墨写 · Flutter Path A

这是桌面手写软件的新开发线：**Flutter + pressure-aware canvas**，直接在 GitHub 分支中推进，不要求本地先搭开发环境。

## 当前分支

`flutter-a-dev`

## 当前阶段：MVP-03

这一阶段开始把“能写”推进到“适合老师长期板书”：

- macOS / Windows 桌面端
- pressure-aware stylus input
- 平滑笔迹
- 画笔 / 橡皮 / 选择
- 黑、红、蓝、绿、黄等常用颜色
- 2 / 4 / 7 / 10 px 快速粗细
- 收藏笔槽
- 钢笔 / 荧光笔预设
- 收藏笔槽左右切换
- Undo / Redo / 清空
- 深色软件壳 + 白色书写区域
- 键盘快捷键
- 无限画布基础能力

## 核心底座

当前采用 `fluera_canvas`。它提供 macOS / Windows 支持、pressure-aware stylus input、平滑处理、橡皮、选择、无限缩放/平移、持久化基础能力以及 Flutter 桌面输入处理。

选择它的原因是：A 路径的重点是**开发效率 + 尽快验证真实手写体验**，而不是第一天自己从 PointerEvent、Path、缓存、命中测试全部造轮子。

## GitHub 云端开发

本项目按照“GitHub 直接开发”的方式推进：

1. 修改代码直接提交到 `flutter-a-dev`。
2. GitHub Actions 自动执行 `flutter analyze` 与 `flutter test`。
3. 同时在 GitHub-hosted macOS / Windows runner 上进行桌面 Release 构建。
4. 本地电脑不承担开发环境和构建环境。
